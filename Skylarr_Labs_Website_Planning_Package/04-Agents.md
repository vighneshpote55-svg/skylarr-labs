# Agents and Responsibilities
Human owner approval is required for company claims, legal/privacy copy, and production release.

## Product Owner / Business Stakeholder
Own goals, audience, franchise terms, eligibility, lead fields, approved claims, acceptance. Confirm investment, statistics, certifications, territory rules, and earnings claims.

## UX and Content Agent
Create journey, wireframes, concise copy, CTA wording, FAQs, content gap list. Never invent company facts.

## Visual Design Agent
Apply Emerald Ink `#064E3B` and Champagne `#F8E7C9`; define responsive components, tokens, image/video treatment, and handoff specs.

## Frontend Engineering Agent
Build responsive components, accessible form, video embeds, CTA behavior, analytics. Keep secrets out of client code; respect reduced motion.

## Backend Engineering Agent
Implement lead API, validation, persistence, BDM routing, CRM/notification adapters, security and retries.

## QA/Accessibility Agent
Test form success/failure, responsive layouts, browsers, keyboard/focus, contrast, reduced motion, screen-reader labels, analytics and regression.

## SEO/Analytics Agent
Metadata, semantic structure, campaign attribution, funnel events, performance checks; avoid unnecessary personal data collection.

## Content/Legal Reviewer
Approve claims, certifications, testimonials/permissions, privacy notice, disclaimers, and imagery rights.

## Handoffs
Approved facts/assets → UX outline → visual design → engineering → QA → stakeholder/legal sign-off → launch. Mark unknown details TBD and omit from public copy.
